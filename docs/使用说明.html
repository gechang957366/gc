每周文献速递 · 使用说明

功率预测 · 气象预报 · 雷达流场重构 / 大模型 · 时序预测

一个自动追踪论文的小工具：每周把上面两个方向的新论文整理成中文速递，带双语摘要、关键技术要点、期刊分区和引用格式。 本说明适用于两个版本：局域网版（我开服务，你在浏览器打开）和免安装本地版（你双击 start.cmd，全在自己电脑上跑）。

一、它能干什么

1. 看每周精选（默认视图）

  • 两个版块：「专业前沿」（功率预测 / 气象预报 / 雷达流场重构）和「算法进展」（大模型 / 时序预测）。
  • 每条文献是一张卡片，包含：英文题名 + 中文题名；英文原文摘要 + 中文译文摘要； 3–5 条关键技术要点（提炼方法与贡献，不是复述摘要）；期刊全名； 有的话还带 中科院分区 / JCR 分区 / 影响因子；GB/T 7714 引用（一键复制）； 原文 / PDF 链接；论文原图（可点开放大）。
  • 本期概述：顶部可展开，一段中文综述 + 本期参考文献清单。
  • 排序按等级：顶刊 → 中科院 1 区 → CCF-A 会议 → Q1 → 2 区 → …，同档内再按相关度。

2. 历史期号 / 换一批 / 收藏

  • 顶部「期号」下拉回看往期（标「最新」的是当前期；后面的 × 删除某一期）。
  • 「换一批」：按当前方向再抓 8 篇新论文，生成新的一期，上一批自动留在历史里。
  • 「收藏」：点卡片上的收藏进收藏夹（存你自己浏览器里，换电脑不同步）。
  • 页签右边的输入框是 在本期内过滤，不联网。

3. 文献检索（像谷歌学术那样按关键词现搜）

  • 输入中文或英文关键词 → 现场去 Scopus / Crossref / arXiv 搜，结果与速递卡片同样式（中文摘要、要点、分区、引用）。
  • 结果同样先按期刊等级、再按相关度排，第一页就是同水平的那一批；「换一批」往后翻同档候选，不重复。
  • 每条可复制 GB/T 7714 / BibTeX / RIS / APA；顶部可导出全部 BibTeX / RIS。
  • 需要 API key（见第五节）。没有 key 也能查一部分（arXiv + 部分开放摘要），但覆盖窄很多。

4. 换研究方向 / 自己新建方向

  • 标题下「方向」下拉切换研究方向，期号、检索、换一批都跟着切；默认方向随时切得回去。
  • 「＋ 新建方向」可以自己加：填 检索关键词（必填，有输入建议）、 优先期刊（搜刊名/ISSN，候选里直接显示分区与影响因子）、 领域旗舰刊（点 ☆ 变 ★，会排最前并标「领域顶刊」）。

二、局域网版怎么用（我开服务，你来访问）

我这边双击 start.cmd，黑色窗口保持打开（关了服务就停）。

你这边：跟我连同一个网络（同样的校园网 / 办公 WiFi / 有线网），浏览器打开我发的地址，形如：

http://10.0.0.23:8099/     ← 以窗口里打印的「局域网」那一行为准
  • 建议 Chrome / Edge。
  • 第一次打不开多半是 Windows 防火墙，我这边点「允许访问」即可。
  • 想放桌面：浏览器菜单 →「更多工具 → 创建快捷方式」。
注意：你的每次「换一批」「现场检索」都是在我的电脑上跑、用我的 API 额度，偶尔点点没问题，别反复刷。

三、免安装本地版怎么用（全在你电脑上）

  1. 把 weekly-paper-portable-*.zip 解压到任意文件夹（路径别太深）。
  2. 双击里面的 start.cmd。
  3. 等 1–3 秒，会自动打开浏览器，地址 http://127.0.0.1:8099/；没自动打开就手动输入。
  4. 黑色窗口不要关（关了服务就停）。停止用 Ctrl+C 或直接关窗口。
不需要装 Node.js：压缩包里已经带了 node.exe（约 90 MB，所以包比较大，正常）。 包里还有 standalone\index.html，双击就能看（不启动服务），适合只想翻一翻。

更新数据：以后每周我发新的 data 文件夹，覆盖到你这里的 data\（先关窗口），再启动就是新一期。别删 data\sources.json、data\journals.json、data\domains.json。

四、数据与隐私

  • 压缩包里不含任何 API key，只有论文数据。
  • 「收藏」存在你自己浏览器里，不会上传。
  • 删掉整个文件夹 = 完全卸载，不写注册表、不装服务。

4.1 如果我是发一个网址给你（GitHub Pages / 静态托管）

那种版本只能看，不能现算：

功能静态网址局域网 / 本地版
浏览、切方向、回看历史期号、收藏、复制引用、导出 BibTeX/RIS✅✅
换一批、现场检索、新建/编辑方向、删期号❌（按钮会藏起来并提示）✅

原因很简单：这些功能要现场访问 Scopus/arXiv 并写文件，必须有后端；静态托管只有网页文件，也没有你的 API key。 静态网址的好处是任何人、任何网络、随时打开（不依赖我电脑开着），适合发到大群里；要现搜就装本地版或连我的局域网。

五、自己配 API key（让检索 / 换一批用你自己的额度）

两个 key，作用不同。只配第一个就能用核心功能；第二个可选（没它就只有英文摘要）。

5.1 Elsevier API key（必需：Scopus 检索与摘要）

申请（免费，学术用途）：

  1. 打开 dev.elsevier.com，邮箱注册并登录；
  2. 用途写「academic research」即可；
  3. 进入 My API Key 页面，复制那串 key。

额度：标准学术 key 20,000 次/周（7 天滚动）。一次检索或取一条摘要各算 1 次； 实测「换一批」约 32 次、「现场检索」约 15–40 次、每周自动更新一个方向约 50 次。

放哪：在速递文件夹里建文本文件：

data\.elsevier-key

文件里只写这一行 key（不要引号、空格、多余换行）。也可以设环境变量 ELSEVIER_API_KEY（优先级更高）。

验证：

cd 你解压的文件夹
node scripts\usage.mjs

会打印配额上限、本周已用、剩余次数、重置时间。若显示「没有配置 key」，检查文件名（前面有个点）与路径是否在 data\ 下。

5.2 DeepSeek API key（可选：中文摘要与本期概述）

  • 到 platform.deepseek.com → API Keys → 新建，复制 sk- 开头那串（只显示一次）。
  • 账户需有余额（充值几十块能用很久，整理一条文献约 1,000 tokens）。
  • 放法二选一：环境变量 DEEPSEEK_API_KEY，或 用户目录\.dsh\.credentials.yaml。
  • 没有它时：英文摘要、引用、分区、排序正常，只是中文摘要与本期概述为空。

5.3 安全提醒

key 就是额度凭据，等同于密码：别发群里、别提交到 GitHub。怀疑泄露就去控制台删除旧 key、重新生成，再替换本地文件。

六、常见问题

现象怎么办
双击 start.cmd 一闪就没 / 提示 node.exe not found 包里缺 node.exe：装一次 Node.js，或找我要完整包。
